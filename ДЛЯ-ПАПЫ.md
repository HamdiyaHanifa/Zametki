# Подключение облака к приложению «Заметки»

Нужно примерно 10 минут. Всё, что требуется от взрослого, — завести аккаунт
и вписать два значения в файл. Код уже написан.

## Зачем

Сейчас заметки хранятся только в памяти браузера: на телефоне их не видно.
Облако (Supabase, бесплатный тариф) даёт синхронизацию между устройствами.

## Почему аккаунт нужен ваш

Регистрация — это согласие с условиями сервиса, и у Supabase есть возрастное
ограничение. Поэтому аккаунт оформляется на взрослого.

## Шаги

1. **Регистрация.** https://supabase.com → Start your project.
   Вход можно сделать через GitHub — отдельный пароль не понадобится.

2. **Создать проект.** Название — например `zametki`.
   Регион выбрать ближайший (Frankfurt подойдёт).
   Пароль базы данных Supabase сгенерирует сам — сохраните его в менеджере
   паролей. В приложении он не используется.

3. **Создать таблицу.** В проекте слева: **SQL Editor** → **New query**.
   Открыть файл `supabase-setup.sql` из этой папки, скопировать целиком,
   вставить и нажать **Run**.
   Внизу должно появиться `rowsecurity = true` — это значит, что защита включена
   и чужие люди читать заметки не смогут. Если там `false` — не продолжайте,
   напишите об этом Claude.

4. **Взять ключи.** Слева **Settings** → **API**. Нужны два значения:
   - `Project URL`
   - ключ `anon` `public` — именно этот, **не** `service_role`

   Ключ `service_role` даёт полный доступ в обход всех проверок. Его нельзя
   вставлять в приложение и нельзя никому пересылать.

5. **Вписать в файл.** В папке проекта скопировать `.env.example` в `.env`
   и заменить заглушки:

   ```
   VITE_SUPABASE_URL=https://xxxxx.supabase.co
   VITE_SUPABASE_ANON_KEY=eyJhbG...
   ```

   Файл `.env` уже указан в `.gitignore` — на гитхаб он не попадёт.

6. **Перезапустить приложение.** В терминале в папке проекта: `npm run dev`.
   Перезапуск обязателен — Vite читает `.env` только при старте.
   В правом нижнем углу появится кнопка «Облако».

7. **Вход в приложении.** Нажать «Облако» → ввести почту → прийдёт письмо
   со ссылкой. Пароль не нужен. Под этой же почтой войти на другом
   устройстве — заметки синхронизируются.

## Про безопасность

Ключ `anon` не секретный: он виден всем в коде любого сайта на Supabase.
Безопасность обеспечивает не он, а Row Level Security — правила из пункта 3,
которые разрешают каждому пользователю видеть только свою строку.
Поэтому пункт 3 пропускать нельзя.

## Если что-то не вышло

Приложение продолжает работать без облака — заметки просто хранятся
в браузере, как раньше. Ничего не потеряется.
